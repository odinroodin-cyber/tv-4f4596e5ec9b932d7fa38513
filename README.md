# 台北市簡易估價原型

以內政部與臺北市地政局公開實價登錄，依自行輸入的門牌，在瀏覽器內試算臺北市房地單價與總價區間。也可拍照或選取土地／建物登記謄本，於本機辨識後帶入門牌、樓層、屋齡與坪數。純靜態網站，不上傳地址或謄本，不使用付費服務，也不把謄本圖檔或文字寫入 localStorage。

## 檔案

- `index.html`：介面（繁體中文）
- `app.js`：地址解析、比較案例配對與試算
- `transcript.js`：謄本欄位解析（平方公尺 ×0.3025 為坪）
- `ocr.js`：本機 PDF 文字層或 Tesseract.js（chi_tra + eng，免費 CDN）
- `transcript-ui.js`：拍照讀謄本介面
- `data/taipei_sales.json`：已清理的成交資料（863 筆）

請以靜態網站方式發佈（例如 GitHub Pages）。直接用檔案路徑（`file://`）開啟時，瀏覽器可能會擋住 JSON 與 CDN 腳本。

## 資料範圍與限制

見網站內「資料涵蓋範圍」與「使用限制」。本批不是完整的兩三年官方季節檔；2019–2025 年樣本偏少。光學辨識可能誤讀，這不是鑑價。
