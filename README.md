# 台北市簡易估價原型

以內政部與臺北市地政局公開實價登錄，依自行輸入的門牌，在瀏覽器內試算臺北市房地單價與總價區間。純靜態網站，不上傳地址，不使用付費服務。

## 檔案

- `index.html`：介面（繁體中文）
- `app.js`：地址解析、比較案例配對與試算
- `data/taipei_sales.json`：已清理的成交資料（863 筆）

請以靜態網站方式發佈（例如 GitHub Pages）。直接用檔案路徑（`file://`）開啟時，瀏覽器可能會擋住 JSON 載入。

## 資料範圍與限制

見網站內「資料涵蓋範圍」與「使用限制」。本批不是完整的兩三年官方季節檔；2019–2025 年樣本偏少。這不是鑑價。
